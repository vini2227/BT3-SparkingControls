# BT3 Sparking Controls — 1.0.6 Beta

## คู่มือการควบคุมและการติดตั้ง

รูปแบบการควบคุมและ HUD ต่อสู้ที่ได้แรงบันดาลใจจาก Sparking! ZERO สำหรับ Tenkaichi3Decomp แอนิเมชัน ความเสียหาย ค่า Ki ระยะ ความสามารถ และช่วงเวลาที่ทำท่าได้ยังเป็นกฎของ BT3 ไม่รวมตัวเกมหรือทรัพยากรของเกม

## สิ่งที่เปลี่ยนแปลงในรุ่น 1.0.6 Beta

- Windows และ Linux: เมนูทั้งสี่อยู่ด้านซ้ายภายในมุมมองของผู้เล่นแต่ละคน โดยมีขนาดคงที่สำหรับ 4:3, 16:9, 16:10 และจอกว้างพิเศษ Windows: ตรวจสอบความเข้ากันได้แบบปรับตัวและตรวจจับ Decomp ต้นฉบับ, Char Package และ Tag Team อัตโนมัติ พร้อมข้อมูลตัวละครปรับแต่งและคอนโทรลเลอร์ในเครื่องสูงสุดสี่ตัว Linux 1.0.6 มีผังแบ่งหน้าจอใหม่ แต่คงไลบรารีและตัวตรวจสอบเดิมที่ทดสอบกับ v0.1.37/v0.1.38.1 ไม่รวมการรองรับรุ่นดัดแปลงของ Windows ใน Tag Team แบบสี่หน้าจอจะแสดงคำใบ้ boost เดิมโดยไม่มีไอคอนซ้อนเพิ่ม Char Package ปิดตัวละครปรับแต่งในการเล่นออนไลน์เอง การทดสอบอัตโนมัติไม่แทนการแข่งขันจริง ยังไม่ได้ตรวจสอบ Linux แบบเนทีฟและ rollback ออนไลน์ ไม่รับประกันทุกเวอร์ชันในอนาคตหรือการปราศจาก desync ทั้งหมด

## การติดตั้ง

### Windows x64

แตก ZIP สำหรับ Windows เปิด `BT3-SparkingControls.exe` คลิก **Browse** เลือก `Tenkaichi3Decomp.exe` ตั้งค่าภาษาและหน้าตา แล้วคลิก **Save and start** ให้เปิดเกมผ่านโปรแกรมช่วยเสมอ EXE ของ Windows รวมทรัพยากรของโปรแกรมช่วยไว้แล้ว จึงส่งเฉพาะ EXE เพื่อใช้งานทั่วไปได้ แต่ผู้รับต้องมีเกมเอง ZIP มีซอร์สโค้ดและใบอนุญาตด้วย ไม่ต้องใช้ modloader คอมไพล์เกมใหม่ หรือแทนที่ไฟล์เกม

`%LOCALAPPDATA%\BT3-SparkingControls`

### Linux x64

แตก ZIP Linux x64 ทั้งหมด และเก็บ EXE แบบ managed, `libbt3sparking.so`, โปรไฟล์และทรัพยากรไว้ด้วยกัน ติดตั้ง Mono ที่รองรับ Windows Forms/System.Web.Extensions, libgdiplus และฟอนต์ภาษาที่ใช้ ต้องใช้ X11 พร้อม compositor หรือ XWayland ที่ทำงานได้ เปิดเทอร์มินัลในโฟลเดอร์แล้วรัน `bash start.sh` เลือกเกม **Linux แบบเนทีฟ** แล้ว Save and start EXE ใช้ Mono ไม่ต้องใช้ Wine/Proton ยังไม่รองรับ Wayland แบบเนทีฟ ไลบรารีคอมไพล์ข้ามระบบโดยใช้ glibc 2.35 เป็นเป้าหมาย ระบบอื่นอาจต้องรัน `bash build.sh` อย่าเปิดเกมอีกชุดแยกต่างหาก

`$XDG_DATA_HOME/BT3-SparkingControls/linux` · `~/.local/share/BT3-SparkingControls/linux`

`linux-runtime` · `linux-online-v0.1.37` → `linux`

```bash
bash start.sh --check /path/to/Tenkaichi3Decomp
```

## การควบคุม

□ = สี่เหลี่ยม, △ = สามเหลี่ยม, ○ = วงกลม, LS = อนาล็อกซ้าย ลูกศร LS หมายถึงอนาล็อก ไม่ใช่ D-pad เมนูปกติยังใช้การควบคุมเดิม

| ปุ่ม / ชุดคำสั่ง | การทำงาน |
| --- | --- |
| `□` | โจมตี Rush |
| `△` | ยิง Ki |
| `X` | เคลื่อนที่และพุ่งแบบเดิม |
| `R2` | ชาร์จ Ki |
| `L1` | ลอยขึ้น |
| `L2` | ลอยลง |
| `R2 + L1` | Z Dash แนวตั้งขึ้น |
| `R2 + L2` | Z Dash แนวตั้งลง |
| `R1` | ป้องกันนอกคอมโบของตนที่รองรับ |
| `R2 + □` | ท่าพิเศษ 1 |
| `R2 + △` | ท่าพิเศษ 2 |
| `R2 + ○` | ท่าไม้ตายตามเงื่อนไขเดิม |
| `R2 + D-pad ↑ / ↓` | สกิล 1 |
| `R2 + D-pad ← / →` | สกิล 2 |
| `○` | ท่าตั้งรับสวนกลับเดิม |
| `R1 (combo)` | วาร์ปไปด้านหน้าในคอมโบที่รองรับ |
| `R1 + LS (combo)` | วาร์ปตามทิศทางในคอมโบดังกล่าว |
| `R1 + □` | จับตามปกติ |
| `R1 + LS↓ + □` | จับศัตรูล้มแบบทางเลือก ใช้อนาล็อกเท่านั้น |
| `LS↑ + △` | จับศัตรูล้มด้วยคำสั่งเดิม |
| `R3` | Emergency Blaster Wave เมื่อผ่านเงื่อนไขเดิม |
| `L3` | ค้นหา / ล็อกเป้าหมาย |
| `Select / View` | เปลี่ยนกล้อง |
| `D-pad ↑` | กดค้าง: แปลงร่าง/ฟิวชัน |
| `D-pad ←` | กดค้าง: สลับสมาชิกทีม |
| `D-pad ↓ / → (no R2)` | ถูกบล็อกระหว่างต่อสู้เพื่อกันกดพลาด |

เลือกท่าพิเศษได้ขณะกด R2 ค้างอยู่ หากต้องการชาร์จต่อให้ค้างปุ่มโจมตีที่กำหนด การปล่อยเฉพาะ R2 จะไม่ปล่อยปุ่มโจมตี เมื่อมีคำแนะนำ boost ให้ใช้ □ + ทิศทางที่ระบุ ภาพซ้อนทับจะแทนเฉพาะสามเหลี่ยมและไม่บังรูปมือ คีย์ลัดสกิลเป็นรูปแบบของโปรแกรมนี้ ไม่ใช่การจำลอง ZERO ทุกปุ่ม

○ เรียกท่าสวนกลับเดิมของ BT3 โดยมีลำดับก่อนปุ่มโจมตีที่กดค้างในคอมโบที่รองรับ ไม่ใช่ระบบ Perception/Super Perception ทั้งหมดของ ZERO วาร์ป R1 ยังต้องมี Ki และจังหวะยกเลิกตามเกมเดิม ไม่รับประกันว่าจะอยู่หลังศัตรูหรืออยู่กับที่ R1 + □ มีลำดับก่อนและส่ง X–ปล่อย–X แต่ยังต้องอยู่ในระยะและจังหวะที่ถูกต้อง ยังคงการกด X สองครั้งเดิมไว้ การจับศัตรูล้มไม่ใช้ D-pad ↓ และ LS↑ + ○ จะไม่เรียกท่านี้ R3 ใช้พลังชีวิตและเงื่อนไขของ BT3 ไม่ใช่ Revenge Counter ที่ใช้ Skill Count ของ ZERO คำสั่งแปลงร่าง/ฟิวชัน R3 เดิมจะถูกดักไว้ และการ์ดสร้างคำสั่งที่ต้องใช้ภายใน

## แปลงร่าง ฟิวชัน และสลับตัว

กด D-pad ↑ ค้างแล้วเลือก □/△/X/○ ตามการ์ด ปล่อย ↑ เพื่อปิด L1/R1 สลับหมวดได้เมื่อมีทั้งแปลงร่างและฟิวชัน ข้ามหมวดว่างและเปิดฟิวชันทันทีถ้ามีเพียงอย่างเดียว กด D-pad ← ค้างเพื่อสลับทีม ยังต้องผ่านเงื่อนไขคู่ร่วมร่าง รูปแบบ เกจ คูลดาวน์ และสถานะการต่อสู้ของ BT3 ทั้งสามเมนูใช้ตำแหน่งการ์ดคงที่ แสดงช่องว่างและแถบชีวิตตัวสำรอง ออนไลน์จะแสดงแผงของผู้เล่นในเครื่องทางซ้ายแม้เป็นผู้เล่น 2 โดยไม่เปลี่ยนฝั่งอินพุตจริง

## HUD และการตั้งค่า

กด R2 ค้างเพื่อแสดงท่า ปุ่มและค่าใช้จ่าย **Centered** สมดุลระหว่างกลางและขอบ **Expanded** เพิ่มระยะระหว่างแผง **Classic (4:3)** ใช้พื้นที่เดิม 4:3 รักษาตำแหน่ง 4:3 เนทีฟและใช้พื้นที่ปลอดภัยบน ultrawide ซ่อนรายการโจมตีได้ กรอบนอกปิดเป็นค่าเริ่มต้นสำหรับการตั้งค่าใหม่ ใช้ภาพ HD ที่มีอยู่ก่อน แล้วจึงใช้ต้นฉบับ ไม่แถมแพ็กพื้นผิว มีธีมมืด ปุ่มมน ลูกแก้วสามดาว พรีวิว และ 16 ภาษารวมอาหรับ RTL ชื่อท่า/ตัวละครมาจากเกม **F6** สลับการแสดงท่า **F7** กรอบ **F8** ตำแหน่ง คลิกปุ่มคีย์ลัดเพื่อเปลี่ยน ปิด หรือคืนค่าเริ่มต้น ไม่อนุญาตคีย์ซ้ำ ทำงานเมื่อเกมมีโฟกัสและไม่ทำซ้ำเมื่อกดค้าง ล็อกไม่ให้เปลี่ยนระหว่างต่อสู้ได้ บันทึกพาธ ภาษา หน้าตา คีย์ลัด และสิ่งที่เปลี่ยนในเกมข้ามการเปิดใหม่/อัปเดต ถ้าย้ายเกมให้เลือกพาธใหม่
