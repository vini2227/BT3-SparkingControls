# BT3 Sparking Controls — 1.0 Beta

## دليل التحكم والتثبيت

تخطيط تحكم وواجهة قتال مستوحيان من Sparking! ZERO للعبة Tenkaichi3Decomp. تظل الرسوم الحركية والضرر وتكلفة Ki والمدى والقدرات ونوافذ تنفيذ الحركات خاضعة لقواعد BT3. اللعبة ومواردها غير مرفقة.

## التثبيت

### Windows x64

فك ضغط ZIP الخاص بـ Windows وشغّل `BT3-SparkingControls.exe`، ثم اضغط **Browse** واختر `Tenkaichi3Decomp.exe`. حدد اللغة والمظهر واضغط **Save and start**. ابدأ اللعبة دائماً عبر البرنامج المساعد. يحتوي EXE الخاص بـ Windows على موارد المساعد ويمكن مشاركته منفرداً للاستخدام العادي، لكن المستلم يحتاج نسخته من اللعبة. يتضمن ZIP أيضاً المصدر والترخيص. لا تحتاج إلى محمّل تعديلات أو إعادة ترجمة اللعبة أو استبدال ملفاتها.

`%LOCALAPPDATA%\BT3-SparkingControls`

### Linux x64

فك ضغط ZIP الخاص بـ Linux x64 كاملاً، واحتفظ بملف EXE المُدار و`libbt3sparking.so` والملفات التعريفية والموارد معاً. ثبّت Mono مع دعم Windows Forms/System.Web.Extensions وlibgdiplus وخطوط اللغة. استخدم X11 مع مؤلف رسومي أو XWayland يعمل بصورة صحيحة. شغّل `bash start.sh` من المجلد واختر ملف اللعبة **الأصلي لنظام Linux** ثم Save and start. يعمل EXE عبر Mono دون Wine/Proton. Wayland الأصلي غير مدعوم. استهدفت المكتبة glibc 2.35 عند الترجمة المتقاطعة؛ قد يلزم `bash build.sh` لنظام مختلف. لا تشغّل نسخة ثانية من اللعبة بصورة منفصلة.

`$XDG_DATA_HOME/BT3-SparkingControls/linux` · `~/.local/share/BT3-SparkingControls/linux`

`linux-runtime` · `linux-online-v0.1.37` → `linux`

```bash
bash start.sh --check /path/to/Tenkaichi3Decomp
```

## التحكم

□ = مربع؛ △ = مثلث؛ ○ = دائرة؛ LS = العصا اليسرى. أسهم LS تعني العصا لا أزرار الاتجاهات D-pad. تحتفظ القوائم العادية بتحكم اللعبة الأصلي.

| الزر / المجموعة | الإجراء |
| --- | --- |
| `□` | هجمات Rush |
| `△` | طلقات Ki |
| `X` | الحركة والاندفاع الأصليان |
| `R2` | شحن Ki |
| `L1` | الصعود |
| `L2` | الهبوط |
| `R1` | الدفاع خارج مجموعات هجماتك المدعومة |
| `R2 + □` | الهجوم الخارق 1 |
| `R2 + △` | الهجوم الخارق 2 |
| `R2 + ○` | الهجوم النهائي وفق شروط اللعبة |
| `R2 + D-pad ↑ / ↓` | المهارة 1 |
| `R2 + D-pad ← / →` | المهارة 2 |
| `○` | وضعية الهجوم المضاد الأصلية |
| `R1 (combo)` | انتقال أمامي أصلي أثناء مجموعات الهجمات المدعومة |
| `R1 + LS (combo)` | انتقال باتجاه محدد أثناء تلك المجموعات |
| `R1 + □` | إمساك عادي |
| `R1 + LS↓ + □` | إمساك أرضي بديل باستخدام العصا فقط |
| `LS↑ + △` | إمساك أرضي بالأمر الأصلي |
| `R3` | Emergency Blaster Wave عند استيفاء شروط اللعبة |
| `L3` | البحث / تثبيت الهدف |
| `Select / View` | تغيير الكاميرا |
| `D-pad ↑` | استمرار الضغط: التحولات/الاندماجات |
| `D-pad ←` | استمرار الضغط: تبديل عضو الفريق |
| `D-pad ↓ / → (no R2)` | محظورة أثناء القتال لمنع الأوامر غير المقصودة |

يمكن اختيار الهجمات الخاصة مع استمرار الضغط على R2. لمواصلة شحن هجمة، استمر في ضغط زر الهجوم المخصص؛ تحرير R2 وحده لا يحرر ذلك الزر. عند ظهور طلب التعزيز، استخدم □ مع الاتجاه المطلوب لإرسال أمر boost الأصلي. يغطي الرمز المثلث فقط ويترك رسم اليد ظاهراً. اختصارات المهارات ليست نسخة مطابقة لتحكم ZERO.

يطلب ○ وضعية BT3 المضادة، بأولوية على أزرار الهجوم المضغوطة خلال المجموعات المدعومة، ولا يضيف نظام Perception/Super Perception الكامل من ZERO. تحتفظ انتقالات R1 بتكلفة Ki ونوافذ الإلغاء الأصلية ولا تضمن الظهور خلف العدو أو البقاء في المكان. يأخذ R1 + □ الأولوية ويولد X ثم تحريره ثم X، مع بقاء قيود المدى والتوقيت. يبقى ضغط X مرتين الأصلي متاحاً. الإمساك الأرضي لا يقبل D-pad ↓، ولا ينفذه LS↑ + ○. يستخدم R3 تكلفة الصحة وشروط BT3 لا Revenge Counter المعتمد على Skill Count في ZERO. تُستهلك اختصارات R3 المادية الأصلية للتحول/الاندماج، وتولّد البطاقات الأوامر المطلوبة داخلياً.

## التحول والاندماج وتبديل الفريق

اضغط مطولاً D-pad ↑ واختر □/△/X/○ حسب البطاقة؛ حرّر ↑ للإغلاق. يتنقل L1/R1 بين التحول والاندماج فقط إذا توفرت الفئتان. تُتجاوز الفئات الفارغة، وتفتح الشخصيات التي تملك اندماجاً فقط تلك الفئة مباشرة. اضغط مطولاً D-pad ← لتبديل زميل. تظل شروط الشريك والشكل والمقاييس والتبريد وحالة القتال في BT3 مطلوبة. مواقع البطاقات موحدة مع خانات فارغة وأشرطة صحة الاحتياط. عبر الإنترنت تظهر اللوحات المحلية يساراً حتى للاعب 2 دون تغيير الجانب المنطقي للمدخلات.

## الواجهة والإعدادات

اضغط R2 مطولاً لعرض الحركات والأوامر والتكاليف. **Centered** يوازن الوسط والحواف؛ **Expanded** يباعد اللوحات؛ **Classic (4:3)** يستخدم منطقة 4:3 الأصلية. يبقى موضع 4:3 الأصلي محفوظاً وتستخدم الشاشات فائقة العرض مناطق آمنة. يمكن إخفاء الهجمات؛ الإطار الخارجي معطل افتراضياً للإعدادات الجديدة. تُفضّل الموارد عالية الدقة المتوفرة وإلا تُستخدم الأصلية؛ لا توجد حزمة خامات مرفقة. واجهة داكنة وأزرار مستديرة وكرة بثلاث نجوم ومعاينة و16 لغة مع العربية من اليمين لليسار؛ أسماء الحركات والشخصيات من اللعبة. **F6** عرض الهجمات؛ **F7** الإطار؛ **F8** الموضع. انقر زر الاختصار لتغييره أو تعطيله أو استعادة الافتراضي؛ تُرفض التعيينات المكررة. تتطلب الاختصارات تركيز اللعبة ولا تتكرر باستمرار الضغط. يمكن قفل التغييرات أثناء القتال. تُحفظ المسارات واللغة والمظهر والاختصارات والتغييرات داخل اللعبة عبر التشغيل والتحديثات. أعد اختيار المسار إذا نقلت اللعبة.

## التوافق واللعب عبر الإنترنت والاختبارات

يترجم البرنامج حزمة التحكم المحلية ذات 18 بايت قبل أخذ عينة الشبكة؛ يستقبل الطرف الآخر مدخلات BT3 الأصلية. لا يعدّل المدخلات البعيدة أو وظائف اتخاذ القرار القتالي. تُراجع الرموز و61 دالة كاملة ومراجعها لقبول تغييرات العناوين المتوافقة؛ قد تتطلب التغييرات البنيوية أو الرموز المفقودة تحديثاً. اجتازت نسختا Linux v0.1.37 وv0.1.38.1 فحص التوافق، دون ضمان كل الإصدارات. لا تُضاف فترات sleep للتحويلات البسيطة. يستخدم الإمساك وR3 مرحلتين بعينتين لكل حالة؛ يأتي الضغط الثاني بعد نحو 33 مللي ثانية عند 60 هرتز. تتبع البطاقات التوقيت والتأكيد الأصليين؛ المدى والنوافذ وrollback تظل مؤثرة. نجحت 480,183 مراجعة حزم/ABI لـ Windows، و160,061 للحزم و9 للمحمّل المُحاكى لكل إصدار Linux، و2,250 للواجهة و93 للاختصارات و693 للتخطيط لكل واجهة أمامية مع 12 حالة معاينة. اختُبرت واجهة Linux على Windows .NET لا Mono/X11. لم يُتحقق بعد من Linux الفعلي أو وحدات التحكم المادية أو المباريات وrollback الحقيقيين عبر الإنترنت. لا يوجد ضمان شامل لعدم فقدان التزامن.
