BT3 Sparking Controls 1.1 — Linux x64
Extract the entire ZIP. Keep all files together. Run bash start.sh; choose the native Linux game. Requires Mono, libgdiplus, fonts and a composited X11/XWayland session. Read README.md and Controls-and-Setup-Guide.txt.
Settings are retained in the existing XDG directory. Native Linux gameplay has not been tested here.
