# BT3 Sparking Controls — 1.0.6 Beta

## Управление и установка

Раскладка управления и боевой HUD в духе Sparking! ZERO для Tenkaichi3Decomp. Анимации, урон, затраты Ki, дальность, способности и окна действий остаются такими, как в BT3. Игра и её ресурсы не включены.

## Новое в версии 1.0.6 Beta

- Windows и Linux: все четыре меню расположены слева внутри области каждого игрока, со стабильным размером для 4:3, 16:9, 16:10 и сверхшироких экранов. Windows: адаптивная проверка совместимости и автоматическое определение оригинального Decomp, Char Package и Tag Team; данные пользовательских персонажей и до четырёх локальных контроллеров. Linux 1.0.6 включает новый интерфейс, но сохраняет прежнюю библиотеку и механизм определения, проверенные на v0.1.37/v0.1.38.1; варианты Windows не поддерживаются. В режиме четырёх экранов Tag Team остаются штатные подсказки boost без дополнительной накладки. Сам Char Package отключает пользовательских персонажей онлайн. Автоматические тесты не заменяют реальные матчи; нативный Linux и сетевой rollback не проверены. Нет гарантии для всех будущих версий или полного отсутствия рассинхронизации.

## Установка

### Windows x64

Распакуйте ZIP Windows, запустите `BT3-SparkingControls.exe`, нажмите **Browse**, выберите `Tenkaichi3Decomp.exe`, настройте язык и интерфейс и нажмите **Save and start**. Всегда запускайте игру через помощник. EXE Windows содержит свои ресурсы: для обычного использования можно передать только его, но получателю нужна игра. ZIP также содержит исходники и лицензию. Модлоадер, перекомпиляция игры и замена её файлов не требуются.

`%LOCALAPPDATA%\BT3-SparkingControls`

### Linux x64

Распакуйте весь ZIP Linux x64; сохраняйте вместе управляемый EXE, `libbt3sparking.so`, профили и ресурсы. Установите Mono с Windows Forms/System.Web.Extensions, libgdiplus и шрифты языка. Требуется X11 с композитингом или рабочий XWayland. В папке выполните `bash start.sh`, выберите **нативную Linux-версию игры** и Save and start. EXE работает через Mono без Wine/Proton. Нативный Wayland не поддерживается. Библиотека собрана для glibc 2.35; другой системе может потребоваться `bash build.sh`. Не запускайте вторую копию игры отдельно.

`$XDG_DATA_HOME/BT3-SparkingControls/linux` · `~/.local/share/BT3-SparkingControls/linux`

`linux-runtime` · `linux-online-v0.1.37` → `linux`

```bash
bash start.sh --check /path/to/Tenkaichi3Decomp
```

## Управление

□ = Квадрат; △ = Треугольник; ○ = Круг; LS = левый стик. Стрелки LS означают стик, не крестовину. Обычные меню сохраняют исходное управление.

| Кнопка / сочетание | Действие |
| --- | --- |
| `□` | Атаки Rush |
| `△` | Выстрелы Ki |
| `X` | Обычное движение и рывки BT3 |
| `R2` | Зарядка Ki |
| `L1` | Подняться |
| `L2` | Опуститься |
| `R2 + L1` | Вертикальный Z Dash вверх |
| `R2 + L2` | Вертикальный Z Dash вниз |
| `R1` | Защита вне своих поддерживаемых комбо |
| `R2 + □` | Суператака 1 |
| `R2 + △` | Суператака 2 |
| `R2 + ○` | Ультимативная атака по условиям BT3 |
| `R2 + D-pad ↑ / ↓` | Способность 1 |
| `R2 + D-pad ← / →` | Способность 2 |
| `○` | Родная стойка контратаки BT3 |
| `R1 (combo)` | Телепорт вперёд в поддерживаемом комбо |
| `R1 + LS (combo)` | Телепорт по направлению в таком комбо |
| `R1 + □` | Обычный захват |
| `R1 + LS↓ + □` | Альтернативный захват на земле, только стик |
| `LS↑ + △` | Захват на земле исходной командой |
| `R3` | Emergency Blaster Wave при выполнении условий игры |
| `L3` | Поиск / захват цели |
| `Select / View` | Смена камеры |
| `D-pad ↑` | Удерживать: превращения/слияния |
| `D-pad ←` | Удерживать: смена бойца |
| `D-pad ↓ / → (no R2)` | Заблокированы в бою против случайных команд |

Спецприёмы можно выбирать при уже удерживаемом R2. Для продолжения зарядки удерживайте назначенную кнопку атаки: отпускание только R2 не отпускает её. При запросе усиления используйте □ + указанное направление. Накладка заменяет лишь Треугольник, оставляя руку видимой. Сочетания способностей не являются точной копией ZERO.

○ вызывает стойку BT3 с приоритетом над удерживаемыми атаками в поддерживаемых комбо, а не полную механику Perception/Super Perception из ZERO. Телепорты R1 сохраняют родные требования Ki и окна действий; позиция позади врага или неподвижность не гарантируются. R1 + □ имеет приоритет и создаёт X–отпускание–X, с ограничениями дальности и окна. Оригинальный двойной X сохранён. Захват на земле не использует крестовину ↓; LS↑ + ○ его не вызывает. R3 использует здоровье и условия BT3, не очки способностей Revenge Counter из ZERO. Физические исходные команды превращения/слияния R3 перехватываются; карты создают нужные нажатия.

## Превращения, слияние и смена бойца

Удерживайте крестовину ↑ и нажмите □/△/X/○ с карты; отпустите ↑ для закрытия. L1/R1 переключают превращения/слияния только при наличии обеих категорий. Пустые пропускаются; если есть лишь слияние, открывается оно. Удерживайте крестовину ← для смены бойца. Партнёр, форма, шкалы, откаты и состояние боя должны соответствовать BT3. Единые позиции карт, пустые ячейки и здоровье резерва. Онлайн локальные панели слева даже для Игрока 2, без изменения логической стороны ввода.

## HUD и настройки

Удерживайте R2 для списка атак, кнопок и стоимости. **Centered** — баланс центра и краёв; **Expanded** — больше расстояние; **Classic (4:3)** — исходная область 4:3. Нативное 4:3 сохранено, ultrawide использует безопасные области. Атаки можно скрыть; внешняя рамка по умолчанию выключена для новых настроек. Доступная HD-графика предпочтительна, иначе оригинальная; пакет текстур не включён. Тёмный лаунчер, скруглённые кнопки, шар с тремя звёздами, предпросмотр и 16 языков с арабским RTL; имена берутся из игры. **F6**: атаки; **F7**: рамка; **F8**: позиция. Кликните сочетание, чтобы изменить, отключить или сбросить; дубликаты отклоняются. Требуется фокус игры, удержание не повторяет действие. Блокировка запрещает изменения в бою. Путь, язык, настройки, клавиши и изменения в игре сохраняются между запусками/обновлениями. После перемещения игры выберите новый путь.
